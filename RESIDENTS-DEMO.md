# Misery & Co. — Residents & Cat Demo

Open `Misery-Co-Residents.html` in a desktop browser. All game assets are embedded for offline play. Editable source: `residents-source.zip`.

Adds four reference-led animated town characters, three rotating shop customer appearances, and three clickable cat reactions. Keeps the orchard and manual alchemy loop. Uses 2D sprite animation and subtle transforms, not Cubism.

Click the shop cat after each action finishes to cycle yawn, stretch, affection. Town characters can be greeted once per day.
