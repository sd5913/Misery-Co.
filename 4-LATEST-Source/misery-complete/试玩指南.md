# 图形交互版

双击 Misery-Co-Icons.html，无需安装。推荐电脑 Chrome。

- 顶部：日历＝营业日，金币＝余额，爱心＝温暖度；月亮＝打烊。
- 底部：商店、炼金瓶、小镇三个图标切换场景。
- 商店：文游对白框显示客人、短对白和需求图。点猫有打哈欠、伸懒腰、撒娇，不显示动作文字。
- 制作：材料柜取料，每种配方材料各1份，直接入壶。点火 → 按住搅拌 → 按住倾倒 → 自动生成成品。完成后点绿色“回柜台交付”。
- 果园：点天空，再点弹窗玻璃瓶，接满可获得雨水+3，每日一次。其他采集保留。

角色保持参考手绘风格。黑猫使用20姿势帧及淡入淡出过渡；非Cubism模型。
