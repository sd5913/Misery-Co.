# Misery & Co. — Visual UI Revision

Open `Misery-Co-Icons.html` in a desktop browser. Assets are embedded; editable source is in `icons-source.zip`.

Icon-based HUD and navigation; a short visual-novel dialogue panel; reframed adult customers; a tabletop cat with 20 pose frames and blended transitions. Ingredients go directly into the kettle, with one of each ingredient per recipe. The pouring vessel faces the receiving bottle. The green completion control returns to the shop.

In the orchard, click the sky and then the glass bottle to collect rain. One collection per game day, +3 rain. All previous gathering, customers, daily settlement and municipal objectives remain.

Animation uses transparent sprite frames and CSS transforms, not Cubism.
